## Project Overview

**SIPEDULI** — Sistem Pelaporan Kejahatan Terpadu (Integrated Crime Reporting System). A full-stack crime reporting portal where citizens submit reports, an ML model classifies urgency (Tinggi/Sedang/Rendah), and police officers manage cases through an admin dashboard.

---

## Commands

### Full Stack (Docker)
```bash
docker-compose up -d          # Start all services
docker-compose down           # Stop all services
docker-compose logs backend   # View backend logs
```

### Backend (local dev)
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
API docs at `http://localhost:8000/docs`. Backend also needs `nltk.download('stopwords')` on first run.

### Frontend (local dev)
```bash
cd frontend
npm install
npm run dev    # http://localhost:3000
npm run build
```

### Database
```bash
# Start local PostgreSQL via Docker first, then:
python scripts/migrate_csv_to_db.py --env local        # Migrate CSV → PostgreSQL
python scripts/migrate_csv_to_db.py --env production   # Migrate to Supabase
python scripts/test_koneksi.py                         # Test DB connection
```
Initial schema is in [scripts/init.sql](scripts/init.sql) — loaded automatically by Docker on first startup.

### ML
```bash
python backend/app/ml/preprocessor.py   # Quick test of the preprocessing pipeline
```
MLflow UI runs on `http://localhost:5000` (via Docker).

## Architecture

### Services (Docker Compose)
| Service | Port | Description |
|---------|------|-------------|
| `db` | 5432 | PostgreSQL 16 |
| `mlflow` | 5000 | MLflow Tracking Server |
| `backend` | 8000 | FastAPI |
| `frontend` | 3000 | Next.js |

### Backend (`backend/app/`)
- **`main.py`** — FastAPI entry point. All API routers (`laporan`, `auth`, `admin`, `predict`) are currently commented out, to be added incrementally.
- **`core/config.py`** — `Settings` via pydantic-settings; reads from `.env`. Key settings: `DATABASE_URL`, `SUPABASE_URL`, `MLFLOW_TRACKING_URI`, `SECRET_KEY`.
- **`ml/preprocessor.py`** — Production inference pipeline only. Steps: informal→formal normalization → cleaning → stopword removal → Sastrawi stemming → keyword extraction. SMOTE augmentation is strictly offline (in notebooks only).
- **`ml/models/`** — Trained model artifacts (gitignored; regenerate from notebooks).

### Frontend (`frontend/app/`)
- **`page.tsx`** — Public landing page. Single-page with: `Navbar`, `Hero` (live ticket feed), `StatsBar`, `HowItWorks`, `UrgencySystem`, `Tracker` (ticket status lookup), `FAQ`, `Footer`.
- **`laporan/`** — Public report submission form.
- **`admin/dashboard/`** — Admin panel (police officers). Components: `Sidebar`, `TopBar`, `KPI` cards, `MapPanel` (SVG-based Indonesia choropleth), `ReportsTable` with search/filter, `FeedPanel`, `Modal` (report detail with ML results and status update). Currently uses hardcoded mock data — backend integration is pending.

### Database Schema (PostgreSQL)
Five main tables, all in [scripts/init.sql](scripts/init.sql):
- `training_data` — ML training corpus (from CSV migration)
- `laporan` — Citizen reports; ticket IDs (`CRM-YYYY-NNNN`) auto-generated by a DB trigger
- `foto_bukti` — Evidence photos stored in Supabase Storage
- `petugas` — Police officers / admins (bcrypt passwords)
- `ml_models` — Summary of MLflow experiment runs for dashboard display

PostgreSQL ENUMs: `urgensi_level` (Tinggi/Sedang/Rendah), `status_laporan` (Diterima/Dianalisis/Dalam Penyelidikan/Selesai/Ditolak).

### ML Pipeline
Notebooks live in `notebooks/`:
- `01_preprocessing_eda.ipynb` — EDA and data cleaning
- `02_modeling.ipynb` — Model training with MLflow tracking
- `retrain.ipynb` — Retraining on new data

Training data is Indonesian-language crime news. The preprocessor's stopwords intentionally **exclude** `tidak` and `sangat` because they change urgency meaning (e.g., "tidak ada korban" vs "ada korban").

## Key Conventions

- **Indonesian language throughout** — variable names, comments, DB fields, and UI text are in Bahasa Indonesia.
- **Urgency levels**: always use `Tinggi` / `Sedang` / `Rendah` (capital first letter) to match the PostgreSQL ENUM.
- **Frontend**: This project uses **Next.js 16.2.6** with React 19 and **TailwindCSS v4** — APIs and conventions differ from earlier versions. Before editing frontend code, check `frontend/node_modules/next/dist/docs/` for current API references (see `frontend/AGENTS.md`).
- **Model artifacts** are gitignored. Share via MLflow or external storage; regenerate locally from notebooks.
- **`.env` is gitignored** — never commit it. The `.env` in the repo root is an exception tracked for local dev defaults (contains placeholder Supabase credentials).
